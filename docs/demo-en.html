Citation check demo

The LLM is told to cite evidence as [Evidence N], yet it sometimes cites numbers that do not exist. This page replays, in your browser, the rule my Heritage RAG guide uses: fix the numbers at retrieval, parse every citation in the answer, drop the ones that do not exist, and show only the evidence the answer actually used.

Example data. The parsing and filtering code is the same rule as the real service; no LLM is called here.

1Evidence numbers fixed at retrieval

    2Raw LLM answer — edit it and watch the check rerun

    3Citations parsed by code

    4Answer shown to the user

    The code checks that a cited number exists. Whether the sentence is supported by that evidence is handled by the answer rules and by tests with a fake LLM.
