이영주 — 데이터·AI 엔지니어

데이터를 모으고, 모델로 검증하고, 결과로 증명합니다.

지구물리 데이터를 다루며 SCIE 제1저자 논문을 쓴 석사(2026)입니다. 지금은 SSAFY 16기에서 LLM 파이프라인·RAG·모델 앙상블을 만들고 있습니다. 모델이 낸 답을 그대로 쓰지 않고, 코드와 테스트로 다시 확인하는 방식으로 일합니다.

일하는 원칙

원칙LLM에는 판단만 맡기고, 결과는 코드로 다시 확인한다. 번호 범위 검사, 등록된 id만 허용, 인용 번호 검증 같은 규칙을 코드에 둡니다.

연구에서 익힌 방식 — 데이터가 어떻게 만들어졌는지 먼저 보고, 독립된 방법으로 결과를 교차 확인하는 것 — 을 LLM 서비스에도 그대로 적용합니다.

VQA 챌린지 — 멀티모델 확률 앙상블#

이미지+질문 4지선다 VQA. Qwen QLoRA·Gemma·OCR·멀티뷰를 확률 앙상블하고, 후보는 정확도가 아니라 fixes−breaks로 채택

소속SSAFY 16기 AI 챌린지
기간2026.09
역할팀 · 모델 학습·정제 담당
도구PyTorch Hugging Face QLoRA Qwen Gemma OCR
  • 새 모델은 단독 성능이 아니라, 기존 앙상블에 더했을 때 고친 문제와 새로 틀린 문제(fixes−breaks)로 평가
  • 최고 제출을 보호 기준선으로 고정하고 유형별 회귀를 확인한 뒤에만 교체
  • 제출 전 자동 검사(6,714행·ID·확률 행합) + SHA-256 매니페스트로 GPU 없이 재현
