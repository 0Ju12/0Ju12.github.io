연결 설정 및 모델 안내
Codespace를 삭제하거나 새로 만들었다면 편집기 주소 또는 8501 포트 주소를 입력하세요. 이 브라우저에만 저장됩니다.

모델 칸에서 추천 항목을 선택하거나 계정에서 사용할 수 있는 모델 ID를 입력하세요. 기본 모델은 해당 CLI의 기본 설정을 따릅니다. 협업 방식에서는 Codex가 초안을 작성하고 Claude가 검토하며, 검토 의견에 따라 최대 두 번 수정합니다.

Claude 원격 인증이 실패하면 본인 PC에서 claude setup-token을 실행해 발급된 값을 Codespaces 비밀값 CLAUDE_CODE_OAUTH_TOKEN으로 등록한 뒤 Codespace를 다시 시작하세요.
