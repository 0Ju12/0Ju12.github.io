근거 번호 검증 데모

LLM에게 "[근거 N]을 붙여 답하라"고 해도 없는 번호를 붙일 때가 있습니다. 국보 입문 가이드(RAG)가 쓰는 규칙 — 근거 번호를 검색 단계에서 고정하고, 답변의 인용을 코드로 파싱해 없는 번호를 지우고, 실제로 인용한 근거만 보여 주는 과정 — 을 브라우저에서 그대로 재현합니다.

예시 데이터로 동작합니다. 파싱·검사 규칙은 실제 서비스와 같고, 이 페이지는 LLM을 호출하지 않습니다.

1검색 단계에서 고정한 근거 번호

    2LLM 답변 원문 — 직접 고쳐 보면 아래 검사가 바로 다시 돌아갑니다

    3코드가 찾은 인용

    4사용자에게 보여 주는 답

    코드는 인용한 번호가 실제로 있는지를 검사합니다. 문장이 그 근거로 뒷받침되는지는 답변 생성 규칙과 가짜 LLM 테스트로 따로 다룹니다.
