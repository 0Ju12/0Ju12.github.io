중력·자력 탐사 자료를 결합해 아부다비 가샤 암염돔과 지하 기반암 구조를 파악

문제

암염돔과 기반암 구조는 단일 탐사 자료로 해석하기 어려워 서로 다른 물리량을 함께 분석할 필요가 있었음

역할

약 6개월간 캘거리대학교에 파견되어, 중력·자력 탐사 자료의 복합 해석 연구를 수행

한 일

  1. 과학기술정보통신부·IITP 디지털분야 글로벌 인재양성사업(AI·디지털트윈 기반 스마트 CCS 운영 글로벌 인재양성 프로그램) 지원으로 파견
  2. 캘거리대학교 측지공학과 연구진과 함께 항공 중력·자력 데이터의 파수 상관 분석 연구 수행
  3. 칼리파대학교(UAE)와의 3개 기관 공동연구로 확장
  4. 캐나다 로키 카나나스키스(Kananaskis) 지역 현장 지구물리 탐사에 참여하고 영문 현장 탐사 보고서(Field Exploration Report) 공동 작성 (2024.08)

결과

  • 파견 연구 결과로 SCIE 국제학술지 SPE Journal 제1저자 논문 게재 승인 (2026)
  • 같은 연구를 석사 학위논문(2026)으로 완성
