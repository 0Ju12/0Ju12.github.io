이전 시점의 화선·기상·지형 데이터로 다음 시점의 산불 화선을 예측하는 U-LSTM 모델

1학습에 쓰지 않은 강릉 산불에서 정확도 0.90 · F1 0.85
2팀 노트북을 Python 패키지와 테스트로 재구성해 공개

문제

산불은 풍향·풍속·식생에 따라 빠르게 번지지만, 국내에는 실시간 산불 확산 경로를 예측하는 모델이 없었음

역할

팀에서 시공간 딥러닝 모델의 설계와 학습을 맡아, 다음 시점의 산불 확산 범위를 예측하는 것이 목표

한 일

  1. 입력 래스터: 산림청 산불 상황도를 GIS로 디지타이징한 화선 + 기상·NDVI·고도
  2. Conv2D 인코더 → LSTM → Conv2DTranspose 디코더 구조의 U-LSTM 모델을 설계하고, 데이터가 적은 점을 고려해 파라미터 2,736개의 얕은 네트워크로 구성
  3. 부족한 시점 데이터를 길이 1~19의 슬라이딩 윈도우로 확장해 학습 배치 151개 구성
  4. TensorFlow·PyTorch로 모델을 구현하고 Overall Accuracy·F1-score로 검증·평가
  5. 입력 데이터: 4개 대형 산불(울진·삼척, 군위, 밀양, 강릉)의 화선·고도·NDVI·풍향·풍속을 ArcGIS로 2D 래스터화 — 3개로 학습, 1개는 미학습 테스트로 일반화 성능 검증

결과

  • 미학습 산불(강릉) 테스트 Overall Accuracy 0.90 · F1-score 0.85 (검증 0.95 · 0.81) — 초기 시점은 데이터 부족으로 오차가 컸지만 시점이 지날수록 실제 확산 형태를 근접하게 재현
  • 팀 노트북을 설정 파일 기반 Python 패키지로 재구성하고 테스트를 추가해 GitHub에 공개

설계 판단 · 트레이드오프

무엇을 고르고, 그 대신 무엇을 포기했는지

산불 4건뿐인 적은 데이터 → 모델 용량을 키우는 대신 파라미터 2,736개의 얕은 네트워크로 줄이고, 길이 1~19 슬라이딩 윈도우로 학습 샘플(배치 151개)을 늘림
일반화 검증을 위해 산불 1건(강릉)을 학습에서 통째로 빼서 테스트 — 학습 데이터는 더 줄지만 '처음 보는 산불'에서의 성능을 확인

돌아보면 · 남은 과제

다시 한다면 바꿀 것, 아직 남은 것

당시에는 구조 이름만 보고 텐서가 실제로 흐르는 축을 끝까지 확인하지 않았음 — LSTM이 시간이 아니라 공간 축을 보고 있었다는 점을 나중에 알게 됨
다시 만든다면 ConvLSTM, 사건(산불) 단위 교차검증, Dice loss + IoU, 위성 영상 기반 화선 자료부터 추가
