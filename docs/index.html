지구물리 연구원 · CCS 탄성파 모니터링

탄성파 데이터로 이산화탄소 지중저장소를 들여다보는 지구물리 연구자

지구물리컴퓨팅연구실에서 이산화탄소 지중저장(CCS) 부지의 4D 탄성파 모니터링과 해석을 연구하고 환경에너지융합학과 석사 학위를 취득했습니다(2026). 노르웨이 슬라이프너·스메아하이아, 호주 CarbonNet, 캐나다 CaMI FRS 등 해외 대규모 CCS 프로젝트를 분석해 국내 논문 2편과 학회 발표 10건을 수행했고, 2024 한국지구물리·물리탐사학회(KSEG) 추계학술대회에서 학생 우수논문 발표상을 받았습니다. 캐나다 캘거리대학교에서 두 차례 파견 연구를 수행하며 국제공동연구 경험을 쌓았습니다.

프로젝트시공간 딥러닝 기반 산불 확산 경로 예측 모델 2023.09 – 2023.12 전북대학교 IAB 융합전공 · 창의적공학설계 (캡스톤) · 팀원 — 기상·지형·식생 데이터로 다음 시점의 산불 화선을 예측하는 U-LSTM 모델 구축
SITUATION · 상황
산불은 풍향·풍속·임상 등에 따라 급속히 확산되지만, 국내에는 실시간 산불 확산 경로 예측 모델이 없었음
TASK · 역할과 과제
산불 상황도와 기상·지리 데이터로 다음 시점의 산불 확산을 예측하는 딥러닝 모델 구축
ACTION · 한 일
  • 울진·삼척, 군위, 밀양, 강릉 등 4개 대형 산불의 확산 양상을 GIS로 2D 래스터 데이터화 (3개 학습, 1개 테스트)
  • 화선·고도·NDVI(식생지수)·풍향·풍속 5개 변수를 래스터로 구축하고, 부족한 데이터는 time step별 시퀀스를 추가 생성해 보완
  • Conv2D(공간) + LSTM(시계열) + Conv2D Transpose 구조의 U-LSTM 모델을 얕게 설계해 소규모 데이터에 맞춤
RESULT · 결과
  • 검증 정확도 0.95, F1-score 0.81
  • 미학습 산불 테스트 정확도 0.90, F1-score 0.85
