중력·자력 데이터 파수 상관 분석으로 지하 구조 규명 (석사 · SPE Journal 제1저자)

2024.03 – 2026.08 · 지구물리컴퓨팅연구실 · 환경에너지융합학과 · 석사과정 연구원
문제
아부다비 해상 가샤 지역은 암염과 기반암이 8~10 km 두께의 퇴적층 아래에 겹쳐 있어, 중력·자력 신호가 섞이고 기존 해석법은 암염 깊이를 약 6,000 m로 실제(탄성파 기준 약 9,300 m)보다 크게 얕게 추정하는 한계가 있었음
역할
항공 중력·자력 데이터에서 기반암과 암염의 신호를 분리해 각 구조를 규명하는 분석 방법을 제안
한 일
  • 상향 연속·정규화로 중력·자력 데이터를 전처리하고, 파수(wavenumber) 영역에서 두 신호의 상관계수 CC(k)를 계산하는 파수 상관 필터링(WCF) 파이프라인 구축
  • 양의 상관 성분을 강조해 기반암을 드러내는 SLFI, 약한·음의 상관 성분으로 암염을 드러내는 DLFI 두 지표를 설계
  • 기존 3개 독립 모델과 공간 비교·측선별 비교·3D 밀도 모델로 결과를 다각도 검증
  • 정기 연구미팅에서 아부다비 자료 처리·분석 결과를 10회 이상 발표(2024.05–2026.01)하고, 2025.11 기초연구실 워크숍에서 연구 성과 발표
  • IITP 글로벌 인재양성사업 등 국가R&D 과제 참여 연구원
  • 캐나다 캘거리대학교 장기 파견(2024.06–12, 약 6개월): 측지공학과 연구진과 공동 수행, 칼리파대학교(UAE)와 3개 기관 공동연구로 확장
결과
  • SLFI 기반 기반암 구조가 서로 다른 해석법의 기존 독립 모델 3개와 상관계수 0.94 이상으로 일치
  • DLFI로 암염 구조의 공간 분포를 재현하고, 가샤 서쪽의 추가 암염 융기 가능성을 새로 제시
  • SCIE 국제학술지 SPE Journal 제1저자 논문 (2026, 캘거리대·칼리파대 공동연구) · 학회 발표 3건 (2024)
  • 석사 학위논문 「Characterization of Salt and Basement Structures in the Ghasha Area Using Wavenumber Correlation Analysis of Gravity and Magnetic Anomaly Data」 (전북대학교 대학원 환경에너지융합학과, 2026.08.21 학위 취득)

판구조 형성사를 고려한 해외 대규모 CO2 저장소 탄성파 해석 (제1저자 논문)

2022 – 2024.02 · 전북대학교 자원에너지공학과 · 지구물리컴퓨팅연구실 (학부연구생) · 학부연구생 · 제1저자
문제
2050년까지 연간 3,000만 톤급 국내 CO2 저장소 확보가 필요하지만, 대규모 저장소가 어떤 지질 형성 과정을 거쳐 만들어지는지에 대한 체계적인 분석이 부족했음
역할
학부연구생으로 북미·북해·오세아니아·중동의 대규모 CO2 저장소를 판구조론 관점에서 비교 분석하는 연구를 제1저자로 수행 (2023.07 투고 · 2023.12 게재 승인, K-CCUS 온실가스감축 혁신인재양성사업 지원)
한 일
  • GPlates(PALEOMAP PaleoAtlas)로 북미·북해·오세아니아·중동 4개 지역의 판구조 변천사를 복원해 CO2 저장소가 만들어진 과정을 해석
  • 지역별 대표 CCS 프로젝트(북미 Quest·Weyburn-Midale, 북해 Northern Lights·PORTHOS, 오세아니아 Gorgon·Moomba, 중동 Uthmaniyah·카타르 LNG — 지역별 2개씩)의 탄성파 영상화 결과를 저장층·덮개암 지질구조 측면에서 해석
  • 선행 연구: GPU 기반 4D 탄성파 모니터링 기술 적용성 검토 (2022) / 사우디아라비아 딥러닝 기반 탄성파 영상화·노르웨이 슬라이프너 지구물리 모니터링 사례 분석 (2023)
  • 캘거리대학교 단기 파견(2023.12–2024.02): 미국 Utah FORGE 지열 부지 중력 데이터 처리 → 2024 봄 학술대회 포스터 발표
결과
  • 제1저자 논문 「판구조론적 역사를 고려한 해외 대규모 이산화탄소 지중저장소 탄성파 해석 결과 분석」 (Analysis on Seismic Interpretation for Overseas Large-scale CO2 Storage Considering Geological History Related to Plate Tectonics), 지구물리와 물리탐사 27(1), 1–22, 2024 — 학부 과정 연구 성과

IAB 융합전공 — 시공간 딥러닝 기반 산불 확산 경로 예측 모델 (캡스톤)

2023.09 – 2023.12 · 전북대학교 IAB 융합전공 · 창의적공학설계 (캡스톤) · 모델 설계·학습 담당 · 4인 팀
문제
산불은 풍향·풍속·식생에 따라 빠르게 번지지만, 국내에는 실시간 산불 확산 경로를 예측하는 모델이 없었음
역할
팀에서 시공간 딥러닝 모델의 설계와 학습을 맡아, 다음 시점의 산불 확산 범위를 예측하는 것이 목표
한 일
  • 입력 래스터: 산림청 산불 상황도를 GIS로 디지타이징한 화선 + 기상·NDVI·고도
  • Conv2D 인코더 → LSTM → Conv2DTranspose 디코더 구조의 U-LSTM 모델을 설계하고, 데이터가 적은 점을 고려해 파라미터 2,736개의 얕은 네트워크로 구성
  • 부족한 시점 데이터를 길이 1~19의 슬라이딩 윈도우로 확장해 학습 배치 151개 구성
  • TensorFlow·PyTorch로 모델을 구현하고 Overall Accuracy·F1-score로 검증·평가
  • 입력 데이터: 4개 대형 산불(울진·삼척, 군위, 밀양, 강릉)의 화선·고도·NDVI·풍향·풍속을 ArcGIS로 2D 래스터화 — 3개로 학습, 1개는 미학습 테스트로 일반화 성능 검증
결과
  • 미학습 산불(강릉) 테스트 Overall Accuracy 0.90 · F1-score 0.85 (검증 0.95 · 0.81) — 초기 시점은 데이터 부족으로 오차가 컸지만 시점이 지날수록 실제 확산 형태를 근접하게 재현
  • 팀 노트북을 설정 파일 기반 Python 패키지로 재구성하고 테스트를 추가해 GitHub에 공개

POSPEAK(KILL KONG) — 콩글리시 → 원어민 표현 교정 AI (FLAN-T5·Qwen + RAG)

2025.06 – 2025.08 · 포스코 청년 AI·BigData 아카데미 30기 (포스코인재창조원·POSTECH) · 팀 프로젝트 · 데이터 구축·모델 실험 담당 · 팀 프로젝트 · 장려상
문제
한국 학습자가 쓰는 콩글리시와 어색한 격식체 영어는 문법 교정기로 잡히지 않아, 문맥에 맞는 자연스러운 표현으로 바꿔 주는 도구가 필요했음
역할
팀에서 교정 학습 데이터 구축과 모델 실험을 맡아, 단어 단위·문맥 단위 교정 데이터로 T5 계열 모델의 학습 전략을 찾는 것이 목표
한 일
  • [담당] 콩글리시·어색한 표현 → 원어민 표현 쌍으로 이루어진 단어 단위·문맥 단위 교정 데이터셋 구축 및 정제
  • [담당] FLAN-T5를 LoRA로 파인튜닝하고, 학습 전략 3가지(단어→문맥 순차, 문맥→단어 순차, 통합 학습)를 BERTScore로 비교 실험
  • [최종 서비스 'KILL KONG' — POSPEAK의 최종 버전] Qwen-2.5(1.5B) 파인튜닝(Friends 대사 기반 회화체 데이터 2,000건) + 콩글리시 RAG DB 630건 + 사용자별 개인화 메모리(오답노트)를 LangChain으로 결합, React Native·FastAPI 모바일 앱으로 구현
  • [팀] 다국어 문장 임베딩(paraphrase-multilingual-MiniLM)과 FAISS로 유사 교정 예문 top-5를 검색해 모델 입력에 제공하는 RAG 파이프라인과 CLI 구성
결과
  • 순차 학습에서 앞 단계 성능이 떨어지는 catastrophic forgetting(BERTScore F1 0.47 → 0.32)을 실험으로 확인하고 통합 학습으로 전환
  • 통합 학습 모델의 검증 BERTScore F1 약 0.74 (순차 학습 0.32~0.47 대비 개선)
