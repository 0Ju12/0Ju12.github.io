데이터·AI 엔지니어 · 전북대학교 환경에너지융합학과 석사(2026) · SSAFY 16기

지구물리 데이터를 다루며 SCIE 제1저자 논문을 쓴 석사(2026)입니다. 지금은 SSAFY 16기에서 LLM 파이프라인·RAG·모델 앙상블을 만들고 있습니다. 모델이 낸 답을 그대로 쓰지 않고, 코드와 테스트로 다시 확인하는 방식으로 일합니다.

석사 과정에서는 중력·자력 데이터의 파수 상관 분석으로 지하 구조를 규명하는 지표를 설계했고, 캐나다 캘거리대학교와 UAE 칼리파대학교가 참여한 공동연구로 결과를 냈습니다. 학부에서는 판구조 형성사를 고려한 해외 CO2 저장소 탄성파 해석과 시공간 딥러닝 산불 예측을 다뤘습니다.

관심 분야: LLM 응답 검증, 검색 증강 생성(RAG), 데이터 파이프라인, 지구과학 데이터와 딥러닝
