# 이영주 — 데이터·AI 엔지니어

> 복잡한 지구과학 데이터를 딥러닝과 분석으로 풀어내는 데이터·AI 엔지니어

자원에너지공학을 전공하고 환경에너지융합학과에서 석사 학위를 받았습니다(2026). 시공간 딥러닝(U-LSTM) 기반 산불 확산 경로 예측 모델의 설계·학습을 맡아, 학습에 쓰지 않은 산불 사례에서 정확도 0.90, F1-score 0.85를 달성했습니다. 석사 과정에서는 중력·자력·탄성파 등 지구물리 데이터를 분석해 지하 구조를 규명했고, SCIE 국제학술지 SPE Journal 제1저자 논문을 포함해 논문 3편과 학회 발표 10건, 학회 우수논문 발표상의 성과를 냈습니다. 캐나다 캘거리대학교에서 두 차례 파견 연구를 하며 해외 연구진과 협업했고, ADsP(데이터분석 준전문가) 자격을 보유하고 있습니다.

## ⭐ 대표 활동

### 시공간 딥러닝 기반 산불 확산 경로 예측 모델
`AI 프로젝트` · 2023.09 – 2023.12 · 전북대학교 IAB 융합전공 · 창의적공학설계 (캡스톤) · **모델 설계·학습 담당** · 4인 팀

이전 시점의 화선·기상·지형 데이터로 다음 시점의 산불 화선을 예측하는 U-LSTM 모델

- **상황** 산불은 풍향·풍속·식생에 따라 빠르게 번지지만, 국내에는 실시간 산불 확산 경로를 예측하는 모델이 없었음
- **역할·과제** 팀에서 시공간 딥러닝 모델의 설계와 학습을 맡아, 다음 시점의 산불 확산 범위를 예측하는 것이 목표
- **한 일**
  - Conv2D(공간 특징) → LSTM(시계열 특징) → Conv2D Transpose(지도 복원) 구조의 U-LSTM 모델을 설계하고, 데이터가 적고 시계열이 짧은 점을 고려해 네트워크를 얕게 구성
  - 학습 데이터 부족을 time step별 시퀀스 추가 생성으로 보완
  - TensorFlow·PyTorch로 모델을 구현하고 Overall Accuracy·F1-score로 검증·평가
  - 입력 데이터: 4개 대형 산불(울진·삼척, 군위, 밀양, 강릉)의 화선·고도·NDVI·풍향·풍속을 ArcGIS로 2D 래스터화 — 3개로 학습, 1개는 미학습 테스트로 일반화 성능 검증
- **결과**
  - 검증 정확도 0.95, F1-score 0.81
  - 학습에 쓰지 않은 산불 테스트에서 정확도 0.90, F1-score 0.85
  - 초기 시점은 데이터 한계로 오차가 있지만, 후반으로 갈수록 실제 확산 형태를 근접하게 재현

🏷 Python, TensorFlow, PyTorch, U-LSTM, ArcGIS


### 중력·자력 데이터 파수 상관 분석으로 지하 구조 규명 (석사 · SPE Journal 제1저자)
`연구` · 2024.03 – 2026.08 · 지구물리컴퓨팅연구실 · 환경에너지융합학과 · **석사과정 연구원**

겹쳐 있는 중력·자력 신호를 파수 영역 상관 분석으로 분리하는 지표(SLFI·DLFI)를 설계해 암염·기반암 구조를 규명

- **상황** 아부다비 해상 가샤 지역은 암염과 기반암이 8~10 km 두께의 퇴적층 아래에 겹쳐 있어, 중력·자력 신호가 섞이고 기존 해석법은 암염 깊이를 약 6,000 m로 실제(탄성파 기준 약 9,300 m)보다 크게 얕게 추정하는 한계가 있었음
- **역할·과제** 항공 중력·자력 데이터에서 기반암과 암염의 신호를 분리해 각 구조를 규명하는 분석 방법을 제안
- **한 일**
  - 상향 연속·정규화로 중력·자력 데이터를 전처리하고, 파수(wavenumber) 영역에서 두 신호의 상관계수 CC(k)를 계산하는 파수 상관 필터링(WCF) 파이프라인 구축
  - 양의 상관 성분을 강조해 기반암을 드러내는 SLFI, 약한·음의 상관 성분으로 암염을 드러내는 DLFI 두 지표를 설계
  - 기존 3개 독립 모델과 공간 비교·측선별 비교·3D 밀도 모델로 결과를 다각도 검증
  - 관련 연구: GPlates로 해외 대규모 CO2 저장소 형성사를 복원하고 탄성파 영상을 해석(제1저자, 2024), 슬라이프너 탄성파-전자탐사 복합 해석, 스메아하이아 부지 적합성 분석
- **결과**
  - SLFI 기반 기반암 구조가 서로 다른 해석법의 기존 독립 모델 3개와 상관계수 0.94 이상으로 일치
  - DLFI로 암염 구조의 공간 분포를 재현하고, 가샤 서쪽의 추가 암염 융기 가능성을 새로 제시
  - SCIE 국제학술지 SPE Journal 제1저자 논문 (2026, 캘거리대·칼리파대 공동연구) · 국내 제1저자 논문 1편 · 학회 발표 5건
  - 2024 KSEG 추계학술대회 학생 우수논문(포스터) 발표상 · 2026년 석사 학위 취득

🏷 신호처리(파수 영역), 상관 분석, 지표 설계, 중력·자력 데이터, CCS
