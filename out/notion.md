# 이영주 — 데이터·AI 엔지니어

> 복잡한 지구과학 데이터를 딥러닝과 분석으로 풀어내는 데이터·AI 엔지니어

자원에너지공학을 전공하고 환경에너지융합학과에서 석사 학위를 받았습니다(2026). 시공간 딥러닝(U-LSTM) 기반 산불 확산 경로 예측 모델의 설계·학습을 맡아, 학습에 쓰지 않은 산불 사례에서 정확도 0.90, F1-score 0.85를 달성했습니다. 석사 과정에서는 중력·자력·탄성파 등 지구물리 데이터를 분석해 지하 구조를 규명했고, 논문 2편(제1저자 1편)과 학회 발표 10건, 학회 우수논문 발표상의 성과를 냈습니다. 캐나다 캘거리대학교에서 두 차례 파견 연구를 하며 해외 연구진과 협업했고, ADsP(데이터분석 준전문가) 자격을 보유하고 있습니다.

## ⭐ 대표 활동

### 시공간 딥러닝 기반 산불 확산 경로 예측 모델
`AI 프로젝트` · 2023.09 – 2023.12 · 전북대학교 IAB 융합전공 · 창의적공학설계 (캡스톤) · **모델 설계·학습 담당** · 4인 팀

이전 시점의 화선·기상·지형 데이터로 다음 시점의 산불 화선을 예측하는 U-LSTM 모델

- **상황** 산불은 풍향·풍속·식생에 따라 빠르게 번지지만, 국내에는 실시간 산불 확산 경로를 예측하는 모델이 없었음
- **역할·과제** 팀에서 시공간 딥러닝 모델의 설계와 학습을 맡아, 다음 시점의 산불 확산 범위를 예측하는 것이 목표
- **한 일**
  - Conv2D(공간 특징) → LSTM(시계열 특징) → Conv2D Transpose(지도 복원) 구조의 U-LSTM 모델을 설계하고, 데이터가 적고 시계열이 짧은 점을 고려해 네트워크를 얕게 구성
  - 학습 데이터 부족을 time step별 시퀀스 추가 생성으로 보완
  - TensorFlow·PyTorch로 모델을 구현하고 Overall Accuracy·F1-score로 검증·평가
  - 입력 데이터: 4개 대형 산불(울진·삼척, 군위, 밀양, 강릉)의 화선·고도·NDVI·풍향·풍속을 ArcGIS로 2D 래스터화 — 3개로 학습, 1개는 미학습 테스트로 일반화 성능 검증
- **결과**
  - 검증 정확도 0.95, F1-score 0.81
  - 학습에 쓰지 않은 산불 테스트에서 정확도 0.90, F1-score 0.85
  - 초기 시점은 데이터 한계로 오차가 있지만, 후반으로 갈수록 실제 확산 형태를 근접하게 재현

🏷 Python, TensorFlow, PyTorch, U-LSTM, ArcGIS


### 지구물리 데이터 분석 기반 지하 구조 규명 연구 (석사)
`연구` · 2024.03 – 2026.08 · 지구물리컴퓨팅연구실 · 환경에너지융합학과 · **석사과정 연구원**

중력·자력·탄성파 데이터를 분석해 CO2 지중저장 후보지와 지하 구조를 해석

- **상황** 이산화탄소 지중저장(CCS)과 자원 탐사에는 지하 구조를 정확히 파악하는 것이 핵심이지만, 단일 탐사 자료만으로는 해석에 한계가 있음
- **역할·과제** 여러 종류의 지구물리 데이터를 결합·분석해 지하 구조를 규명하고, 해외 대규모 CCS 사례를 분석
- **한 일**
  - 학위논문: 중력·자기 이상 자료의 파수(wavenumber) 상관성 분석으로 아부다비 가샤 지역의 암염돔과 기반암 구조를 특성화
  - 제1저자 논문: GPlates로 북미·북해·오세아니아·중동 대규모 CO2 저장소의 형성사를 복원하고 탄성파 영상을 지질구조 관점에서 해석
  - 노르웨이 슬라이프너 모니터링 자료의 탄성파-전자탐사 복합 해석, 스메아하이아 저장 부지 적합성 분석
- **결과**
  - 제1저자 논문 1편 (지구물리와 물리탐사, 2024), 학회 발표 5건 (2024)
  - 2024 KSEG 추계학술대회 학생 우수논문(포스터) 발표상
  - 2026년 석사 학위 취득
