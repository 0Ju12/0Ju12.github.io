# 보완 체크리스트

- [ ] profile.name — 이름을 입력하세요
- [ ] profile.title — 희망 직무를 입력하세요 (직무에 맞춰 활동 강조점이 달라집니다)
- [ ] education.major — 전공을 입력하세요
- [ ] [예시] 샘플 문구가 23곳 남아 있습니다
- [ ] [예시] 캠퍼스 중고거래 웹 서비스 — 대표 활동인데 증빙 링크(GitHub·발표자료 등)가 없습니다
- [ ] [예시] ○○ 대외활동 / 서포터즈 — STAR의 상황/과제가 비어 있습니다
- [ ] [예시] ○○ 대외활동 / 서포터즈 — 내가 한 일(action)이 비어 있습니다
- [ ] [예시] ○○ 대외활동 / 서포터즈 — 결과(result)가 비어 있습니다
