# 활동 수집 시트

기억나는 대로 **전부** 적으세요. 작아 보이는 활동도 직무와 연결되면 강점이 됩니다.
다 적은 다음에 이 내용을 Claude에게 주면 `portfolio.yaml`로 정리해 줍니다.

## 놓치기 쉬운 활동 체크리스트
- [ ] 수업 팀 프로젝트, 캡스톤디자인, 졸업작품
- [ ] 동아리 · 학회 (운영진 경험 포함)
- [ ] 공모전 · 해커톤 · 경진대회 (수상하지 못한 것도)
- [ ] 대외활동 · 서포터즈 · 기자단
- [ ] 인턴 · 현장실습 · 아르바이트 (직무와 관련된 성과가 있다면)
- [ ] 학부연구생 · 논문 · 학술대회 발표
- [ ] 교육 프로그램 (부트캠프, SW마에스트로, 부스트캠프 같은 국비·기업 교육)
- [ ] 개인 프로젝트 · 블로그 · 오픈소스 기여
- [ ] 튜터 · 멘토 · 조교 · 봉사
- [ ] 자격증 · 어학 · 장학금 · 교환학생

## 활동별로 적을 내용 (복사해서 활동마다 사용)

```
활동명:
유형: (프로젝트 / 대외활동 / 인턴 / 동아리 / 연구 / 수상 / 교육)
기관/소속:
기간: YYYY.MM – YYYY.MM
팀 구성: (예: 4인 — 백엔드 2, 프론트 1, 디자인 1)
내 역할:
한 줄 요약:
[S] 상황 — 어떤 문제나 배경이 있었나?
[T] 과제 — 그중 내가 맡은 일은?
[A] 행동 — 구체적으로 무엇을 했나? (기술, 방법, 의사결정)
[R] 결과 — 무엇이 달라졌나? (숫자로: 사용자 수, %, 시간, 순위, 비용)
사용 기술/키워드:
증빙 자료 링크: (GitHub, 발표자료, 결과물, 기사, 수료증)
```

## 결과를 숫자로 바꾸는 질문
- 몇 명이 썼나? / 몇 명이 참여했나?
- 무엇이 몇 % 빨라지고, 줄고, 늘었나?
- 몇 팀 중 몇 등이었나?
- 시간·비용을 얼마나 아꼈나?
- 숫자가 없다면 **전후 비교**로 써보세요 (예: "수작업 3일 → 자동화 10분").
