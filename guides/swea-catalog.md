# 알고리즘 기록의 SWEA 목록

공식 공개 문제 목록을 페이지 끝까지 수집한 D1~D4 스냅샷은 `content/study_lab/swea-catalog.json`에 있습니다. 문제 번호·제목·난이도·공식 원문 링크만 보관하며 본문·입출력 예제·정답 코드는 수집하지 않습니다.

갱신: `python scripts/refresh_swea_catalog.py`

수집은 D1~D4 필터로 모든 페이지를 읽고, 페이지 누락·중복 번호·중복 ID·난이도 누락을 검사한 뒤 파일을 원자적으로 교체합니다. 갱신 결과를 커밋하고 배포하면 새 목록이 반영됩니다. 빌드 때에는 수집 서버에 의존하지 않습니다.

사용 위치: `/study/index.html#/algo` → 번호·제목 검색 → 풀이·실행. 기존 `/study/lab/index.html` 진입은 알고리즘 기록으로 이동합니다.

코드·입력·메모는 준비 공간 상태의 `algoDrafts`에 문제별 초안으로 저장되며 기존 백업·복구에 포함됩니다. ‘풀이 기록에 저장’을 눌러 사용자가 선택한 결과를 `algo` 기록에 반영합니다. 재저장은 같은 문제 기록을 갱신합니다. 로컬 실행이나 예상 출력 일치는 SWEA 공식 정답 판정이 아닙니다.

초안은 풀이 횟수와 잔디 통계에 포함되지 않습니다. 기존 드라이브 기록은 번호로 연결하고 코드를 편집해 저장해도 드라이브 원본을 바꾸지 않습니다. 실행기는 부모 프레임의 출처·프레임·일회성 토큰을 확인한 메시지만 처리합니다. 노트 암호 키는 메시지에 포함하지 않습니다.

기본 배열 격자·막대와 변수 관찰을 지원합니다. 모든 문제에 대한 정답 알고리즘이나 문제별 전용 애니메이션을 생성한 것은 아닙니다.

## Google Drive 자동 저장

알고리즘 기록의 ‘Google Drive 연결’을 눌러 본인 Google 계정으로 `drive.file` 권한을 허용합니다. Google 로그인 도구가 처음 로드되면 연결 버튼을 한 번 더 누릅니다. 연결 후 ‘풀이 기록에 저장’을 누르면 관리용 `SWEA / 난이도 / 문제번호_제목` 폴더에 `solution.py`, `input.txt`, `output.txt`, `notes.md`, `record.json`을 저장합니다. ‘기존 코드 모두 백업’은 코드가 들어 있는 기존 기록을 저장 대기에 추가합니다.

사용한 OAuth 웹 클라이언트의 승인된 JavaScript 원본은 `https://0ju12.github.io`, 권한은 `https://www.googleapis.com/auth/drive.file`입니다. Cloud 프로젝트에 Google Drive API를 사용 설정하고, OAuth 앱이 테스트 중이면 본인 이메일을 테스트 사용자에 추가해야 합니다. 클라이언트 ID는 공개 설정이며 클라이언트 보안 비밀을 사용하지 않습니다.

접근 토큰은 페이지 메모리에만 유지합니다. 페이지를 다시 열거나 토큰이 만료되면 재연결이 필요합니다. 연결 계정·자동 저장 여부와 대기 중인 기록의 상태만 브라우저에 보관합니다. 인증이 없거나 저장에 실패해도 기록은 남으며, 재연결·재시도로 이어서 저장합니다. 다른 계정으로 연결하면 이전 계정에 보낼 대기 기록을 새 계정으로 전송하지 않습니다.

폴더와 파일은 앱 전용 속성으로 찾아 갱신합니다. 같은 문제를 재저장해도 다섯 파일을 새로 쌓지 않습니다. 파일 공유 설정은 변경하지 않습니다. 자동 저장 끄기·연결 해제는 앞으로의 저장을 중단하고 기존 Drive 파일과 브라우저 기록을 삭제하지 않습니다.

검증: OAuth·Drive API 모의 응답으로 파일 생성/갱신, 토큰 미보관, 인증 만료, 재시도, 계정 변경과 업로드 중 편집을 검사합니다. 실제 사용자 계정의 OAuth 로그인·첫 저장 확인은 사용자가 사이트에서 연결한 뒤 가능합니다.

## 문제 설명·입력 파일 자동 복원

SWEA 공식 상세 페이지와 입력 파일은 로그인이 필요하고, GitHub Pages가 사용자의 SWEA 로그인 쿠키를 공유하지 않습니다. 따라서 이 기능은 공식 사이트에서 모든 문제 본문과 입력을 자동 다운로드하는 기능이 아닙니다.

문제의 ‘풀이·실행’을 연 뒤, 코드 영역의 `input.txt 가져오기`로 내려받은 파일을 선택합니다. 문제 설명은 펼침 영역에 붙여넣거나 설명 `.txt`를 가져오고, 예상 출력도 파일로 설정할 수 있습니다. 이 내용은 문제별 초안과 풀이 기록에 저장되어 다음에 같은 문제를 열면 자동 복원됩니다. Drive 저장 시 문제 설명과 예상 출력도 notes.md·record.json에 포함됩니다.

파일은 1MB·100,000자 이하의 텍스트만 받으며 기존 입력을 바꿀 때는 확인합니다. HTML 문서는 실행하거나 삽입하지 않으며, 문제 설명은 텍스트로만 저장합니다. 공식 입력을 임의 생성하거나 다른 문제의 입력으로 대체하지 않습니다.
