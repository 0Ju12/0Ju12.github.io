# 알고리즘 기록의 SWEA 목록

공식 공개 문제 목록을 페이지 끝까지 수집한 D1~D4 스냅샷은 `content/study_lab/swea-catalog.json`에 있습니다. 문제 번호·제목·난이도·공식 원문 링크만 보관하며 본문·입출력 예제·정답 코드는 수집하지 않습니다.

갱신: `python scripts/refresh_swea_catalog.py`

수집은 D1~D4 필터로 모든 페이지를 읽고, 페이지 누락·중복 번호·중복 ID·난이도 누락을 검사한 뒤 파일을 원자적으로 교체합니다. 갱신 결과를 커밋하고 배포하면 새 목록이 반영됩니다. 빌드 때에는 수집 서버에 의존하지 않습니다.

사용 위치: `/study/index.html#/algo` → 번호·제목 검색 → 풀이·실행. 기존 `/study/lab/index.html` 진입은 알고리즘 기록으로 이동합니다.

코드·입력·메모는 준비 공간 상태의 `algoDrafts`에 문제별 초안으로 저장되며 기존 백업·복구에 포함됩니다. ‘풀이 기록에 저장’을 눌러 사용자가 선택한 결과를 `algo` 기록에 반영합니다. 재저장은 같은 문제 기록을 갱신합니다. 로컬 실행이나 예상 출력 일치는 SWEA 공식 정답 판정이 아닙니다.

초안은 풀이 횟수와 잔디 통계에 포함되지 않습니다. 기존 드라이브 기록은 번호로 연결하고 코드를 편집해 저장해도 드라이브 원본을 바꾸지 않습니다. 실행기는 부모 프레임의 출처·프레임·일회성 토큰을 확인한 메시지만 처리합니다. 노트 암호 키는 메시지에 포함하지 않습니다.

기본 배열 격자·막대와 변수 관찰을 지원합니다. 모든 문제에 대한 정답 알고리즘이나 문제별 전용 애니메이션을 생성한 것은 아닙니다.
